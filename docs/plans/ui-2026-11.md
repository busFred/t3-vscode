# UI round, November 2026 — agreed scope

Mockups: [docs/mockups/transcript-round-fold.html](../mockups/transcript-round-fold.html).
Rule for every item: no new visual language. Reuse the controls the extension already
has (`.work-group-toggle`, borderless `.composer-controls` selects, `--vscode-*`
variables, attachment chips). No bordered cards, pills, segmented controls or emoji.

| # | Item | Decision |
|---|---|---|
| 1 | Account & Usage header | Remove the per-model filter select. Drop the `.usage-display-choice` font/padding override so Pooled matches the account select. |
| 2 | Mid-run images | Images read or produced during a round render as attachment-style chips, not full-width previews. |
| 3 | Permission levels | Fall back across all four upstream levels, including `auto-accept-edits`. |
| 4 | Image context menu | Copy image, Save image as…, Open in editor, Copy reference. |
| 5 | Model picker | Add a Reasoning column and Speed/Ultracode. Raise the width clamp 480 → 560px. |
| 6 | Composer | Resizable by dragging its top edge; height persisted per view; double-click resets. |
| 7 | Round fold | A settled round's intermediate output collapses behind one `.work-group-toggle`. |

## Resolved questions

- **Pooled dropdown size.** It was never shrunk by this round's work. `.usage-account-choice select`
  sets `font-size: .75rem; padding: 3px`; `.usage-display-choice` then overrode it with
  `.625rem` / `padding: 0 2px`. That override, added in `053d19f`, is the entire difference,
  so item 1 deletes it. `flex: none` stays, so it still sizes to its content.
- **Picker congestion.** `ModelPicker.tsx` clamped width to `Math.min(480, innerWidth - 16)`.
  A third column left model names wrapping. 560px gives names a full line; still clamped to
  the window, so narrow editors are unaffected. The Reasoning column also makes Ultrathink
  visible as a real effort level instead of burying it in a `<select>`.
- **Permissions control stays in the composer row**, not the picker footer: it decides whether
  an agent edits unprompted, so it stays where it is read before sending.
- **Fold summary** reads `Worked for 18m 39s` with a `7 steps` meta span, matching the
  existing work-group toggle rather than inventing a new summary format.
- **The reply to a steer is never folded.** Folding hides intermediate output only.
- **Folds nest.** Expanding a round fold reveals the per-step work groups, still collapsed.
- **Collapsed content stays quotable** — the fold is presentation only and must not remove
  rows from selection or the quote path.

## Constraints carried into every item

- Items 6 and 7 touch the composer and transcript, so
  `node scripts/verify-edh.mjs --base-dir <isolated-home> --undo-only` must pass in real
  VS Code and be re-stamped before any VSIX built after them. See the protected-behaviour
  rules in [AGENTS.md](../../AGENTS.md).
- Live provider checks use an explicitly cheap model via `T3_VSCODE_TEST_MODEL` and must
  fail rather than fall back to a premium one.
