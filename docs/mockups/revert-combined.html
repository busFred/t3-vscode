How "both" is detectedThree snapshots per file: turn-start baseline (refs/t3/vscode/turn-start), latest agent checkpoint (refs/t3/orchestration-v2/checkpoints), live working tree. Agent hunks = baseline → checkpoint. Your hunks = checkpoint → working tree. A file with hunks in both diffs shows both tags.
How "Keep" worksBefore restoring: write your hunks (checkpoint → working tree) to a patch per kept file. Restore to the checkpoint. Re-apply each patch with git apply --3way. Untracked kept files are simply excluded from the clean step.
How the verdict is known up frontgit apply --check of each patch against the checkpoint blob runs when the panel opens, so "keeps cleanly" vs "conflicts" is shown before you click anything.
Conflict fallbackNothing is lost: the restored file wins, your version is written as <file>.yours and pushed to a named git stash. The result row offers a Compare link that opens the two in the native diff editor.
