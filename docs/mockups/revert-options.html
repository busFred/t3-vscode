Restore files to this point — design options

Design B: "Edit from here" on a user message rewinds the transcript only. A separate "Restore files to this point" action previews the workspace restore before running git restore --source <checkpoint> --worktree --staged -- . + git clean -fd, which has no dirty-tree check today. These three options highlight human edits (computed by diffing the working tree against the latest agent checkpoint — see revert-options.md) made since the checkpoint so they aren't silently discarded.

A TurnChanges-style panel grouped by who made the change, with per-file "Open diff" and a "Keep" checkbox defaulted on for human-touched files.
