Repair only the list being edited

With List assist enabled, adding a numbered line between existing items automatically repairs the following numbers. Nested lists keep their own sequences; no Renumber icon is needed.

Start numbers are preserved. Code blocks and equations are excluded.

Ctrl/Cmd+Z immediately after a correction undoes the numbering fix while keeping your edit. Ordinary typing does not reapply that same correction; disable List assist when you want manual numbering.

Thin vertical separators divide the groups. In narrow editors, tools wrap naturally and List assist sits at the far right of the final toolbar row. Its highlighted background means enabled; the label stays “List assist”.

Underline inserts literal <u>text</u>; Markdown has no standard underline delimiter.

Keep typing predictable

Enter sends when idle or queues while working. Ctrl/Cmd+Enter steers. Shift+Enter continues a list or starts a normal new line.

Tab / Shift+Tab indent or outdent lists, code and multiline selections; ordinary prose retains focus navigation.

Links remain [text](url). Backticks remain visible. Pasting text keeps its source. With List assist enabled, adding or removing a list item repairs the sequence automatically.

List assist off disables automatic continuation and numbering. Formatting and selection wrapping remain available and undoable.

Responsive editor width

VS Code controls the editor group's minimum width; its public webview API exposes no per-extension minimum-width option. Tab-label sizing does not set the content area's minimum width. VS Code API
