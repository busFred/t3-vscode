# Support

Report reproducible extension problems in [GitHub issues](https://github.com/busFred/t3-vscode/issues).

Include the extension and VS Code versions, operating system, T3 Code version, provider, reproduction steps and expected behavior. Screenshots help for layout problems; remove private messages, tokens and other sensitive information before sharing logs or images.

T3 VSCode is an alpha client for a separately installed local T3 Code server. Linux is the verified platform; remote servers and worktree management are not supported yet. If the same problem occurs in T3 Code's own web interface, report it to [T3 Code](https://github.com/pingdotgg/t3code/issues) and link the report when relevant.
